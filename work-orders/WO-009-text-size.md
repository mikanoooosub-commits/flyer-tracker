# WO-009: 文字を 14px 以上にそろえ、太さを2段にし、入力欄を 16px・数字を等幅にする
- 作成日: 2026-10-14 / 作成: PM / 状態: **受入**（2026-10-14 関所2 オーナー受入。関所1 も同日。軽量コース）
- コース: **軽量**（決まりの適用。機能・データは変えない。仕様レビューと Red Gate は省略、コードレビューは省略しない）
- 画面変更: **あり**（文字の大きさ・太さ）
- 背景: デザイン点検（`docs/デザイン点検_2026-10-14.md`）の No.13〜18。決まりは `docs/デザインの決まり.md` の 5 章（WO-007 で確定、画面への適用は本WO）。
  見直しの3番目の WO（WO-007・WO-008 受入済み → **本WO** → WO-010 文言 → WO-011 部品）。

## 目的
- 屋外のスマホでも読めるよう、**14px 未満の文字をなくす**。
- 文字の大きさと太さの段階を決まりどおりにそろえ、揃って見えるようにする。
- 入力欄の文字を 16px にそろえ、数字を等幅にして桁を読みやすくする。

## 仕様

### 前提の確認（1-0）
- 変えるのは**文字の大きさ・太さ・数字の等幅**だけ。色（WO-007）・押す範囲（WO-008。44px を保つ）・文言（WO-010）・部品の構成と配置（WO-011）は変えない。
- 地図の名前のラベルも決まりどおり **14px にする**（Q-1）。重なりが増えても本WOでは対処しない。
- 今 14px の本文は**上げない**（Q-2）。本WO は 14px 未満をなくすことに絞る。

### 仕様項目（S-n）
- **S-1（最小 14px）**: 画面に出る文字で **14px 未満を 0 件**にする。今の 14px 未満は点検時の数で次のとおり（実装時に数え直す）:
  - `text-xs`（12px）約50か所・`text-[11px]` 1か所 → `text-sm`（14px）。共通の部品（`ui/badge.tsx`・`ui/select.tsx` の見出し）を含む。
  - `globals.css` の地図まわり: 名前のラベル `.flyer-label`（11px）・ピンの履歴 `.flyer-history`（12px）・小学校の吹き出し `.flyer-school-popup`（13px）・メモの吹き出し `.flyer-note-tip`（12px）→ 14px（Q-1）。
  - 上の一覧に無いものも、画面で測って 14px 未満が見つかれば直す（WO-008 の振り返り: 点検の一覧から仕様を作ると漏れる）。
- **S-2（大きくなった分の収まり）**: 文字が大きくなった所は、**折り返して行を増やす**ことで収める（文字を切って隠す・横にはみ出す、を新たに起こさない）。今すでに `truncate` 等で省略している所はそのままでよい。375px で横にはみ出さない。
- **S-3（太さ 2 段）**: `font-medium`（500）は外して通常（400）に、`font-extrabold`（800）は `font-bold`（700）にする。CSS の `font-weight` も 400・700 以外を使わない。
- **S-4（入力欄 16px）**: 入力欄・複数行の入力欄・セレクトの表示部分（`SelectTrigger`）の文字を、スマホ・PC とも **16px** にする（`ui/input.tsx`・`ui/textarea.tsx` の `md:text-sm` を外す、`SelectTrigger` を `text-base`）。セレクトの選択肢（開いたときの一覧）は 14px のままでよい。
- **S-5（数字の等幅）**: 枚数・件数・集計・日付・日数など、**数字を並べて読む所**に `tabular-nums` を付ける（点検の例: 一覧のカードの枚数、一覧の集計、PC の表〔済み〕。ほかに小学校マスタの前回配布日・解禁日・クールダウンの日数、変更履歴の日時）。付けた場所の一覧を report に書く。
- **S-6（変えないもの）**: 今 14px 以上の文字の大きさ（Q-2）・色・文言・押す範囲（44px）・画面の構成は変えない。地図右下の著作権表示（Leaflet・OpenStreetMap）は範囲外（WO-008 と同じ扱い）。

### 前提・不変条件
- DB 変更なし。`docs/デザインの決まり.md` の決まり（トークンだけを使う・直書き禁止・透明度付きの禁止）を守る。
- 地図のピンの色の方針・デモ表示モードは変えない。

### 境界ケース（E-n）
- **E-1**: 地図で名前のラベルが 14px になっても、ピンを押して吹き出しを開ける（ラベルがピンの押す範囲を覆わない）。
- **E-2**: 長い校名・長いメモ・長い配布場所名が、375px のカード・ダイアログ・地図の吹き出しで折り返して全部読める（今省略している所を除く）。
- **E-3**: 下のタブの文字が 14px になっても、3つのタブが1行に収まり、WO-008 の上端の線・高さが崩れない。
- **E-4**: 評価のバッジが 14px になっても、一覧のカードの1行目が崩れない（折り返すなら折り返して読める）。
- **E-5**: iOS で入力欄を押しても、画面が自動で拡大されない（入力欄 16px）。
- **E-6**: 375px で、ログイン・地図・一覧・小学校マスタ・各ダイアログのどれも横にはみ出さない。

### 非機能
- スマホ（主）・PC とも。性能への影響なし。

### 範囲外（やらないこと）

- 文言（WO-010）。部品の統一・配置（WO-011）。色の値（WO-007 で確定）。
