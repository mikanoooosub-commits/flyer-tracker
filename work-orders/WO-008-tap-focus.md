# WO-008: 押す場所を 44px にそろえ、画面の拡大を許し、フォーカスを見分けやすくする
- 作成日: 2026-10-14 / 作成: PM / 状態: **仕様承認**（2026-10-14 関所1 オーナー承認。軽量コース）
- コース: **軽量**（見た目の決まりの適用。機能・データは変えない。仕様レビューと Red Gate は省略、コードレビューは省略しない）
- 画面変更: **あり**（押す範囲・フォーカスの輪・下のタブ）
- 背景: デザイン点検（`docs/デザイン点検_2026-10-14.md`）の No.19〜28 と、WO-007 からの持ち越し（主ボタン等のフォーカスの輪が塗りに接して見分けにくい）。
  決まりは `docs/デザインの決まり.md`（押す場所 44px）。見直しの2番目の WO（WO-007 受入済み → **本WO** → WO-009 文字 → WO-010 文言 → WO-011 部品）。

## 目的
- スマホで押す場所（ボタン・リンク・チェックボックス・ダイアログの「×」・地図の印）を、**見た目を大きく変えずに**押せる範囲 44px 以上にする。
- 画面の拡大（ピンチ）を許す。
- キーボードで操作したときのフォーカスが、どの部品でも見分けられるようにする。

## 仕様

### 前提の確認（1-0）
- 変えるのは**押せる範囲・フォーカスの見え方・画面の拡大の可否・下のタブの「今いる場所」の示し方**だけ。色（WO-007 で確定）・文字の大きさ（WO-009）・文言（WO-010）・部品の構成（WO-011）は変えない。
- 画面の拡大（ピンチ）は**許す**（Q-1）。

### 仕様項目（S-n）
- **S-1（押す範囲 44px）**: 次の押す場所は、押せる範囲を**縦横 44px 以上**にする。見た目の大きさは変えなくてよい（余白・透明の範囲・最小の高さで広げる）:
  - `ui/button.tsx` の `size="sm"`（今 36px・16か所）と `size="icon"`（今 40px・4か所）＝点検 No.20
  - ダイアログの「×」（`ui/dialog.tsx`、今 約16px、ダイアログ12個すべて）＝No.19
  - ヘッダーの「戻る」（36px）、PC の表の操作ボタン（32px）＝No.21
  - 自前のボタン・チップ（種別の切替、メモの色のチップ、住所検索の結果と検索欄）＝No.22
  - 文字のボタン・リンク（ログインの「初回の方…」「パスワードでログインに戻る」、小学校マスタの「地図で位置を指定」「立ち位置（n）」の開閉、外部リンク）＝No.23（CLAUDE.md の既知の軽微 R-6 を閉じる）
  - チェックボックス（ラベル込みで 44px。地図の「現在地トラッキング」、一覧の絞り込みの2つ）＝No.24
  - 地図メモの印（今 24px。評価のピンと同じく透明の余白で当たり判定を広げる）＝No.25
- **S-2（隣どうしの押し間違い）**: 押す範囲を広げた結果、隣の押す場所と範囲が重ならないこと（重なる場合は間隔をあける）。
- **S-3（ダイアログの「×」のフォーカス）**: 「×」の `focus:outline-none` をやめ、他の部品と同じフォーカスの輪を出す＝No.19。
- **S-4（フォーカスの輪）**: すべての押す部品で、キーボードで選んだとき（`focus-visible`）に輪が見える。**主ボタン・削除ボタンなど塗りの部品では、輪と塗りの間に地の色のすき間（オフセット）を入れ**、輪が塗りに接して見分けにくい状態をなくす（WO-007 からの持ち越し）。
  輪の色は WO-007 のトークン（不透明・3:1 以上）を使う。
- **S-5（画面の拡大）**: `layout.tsx` の `maximumScale: 1` を外し、画面の拡大を許す（Q-1）＝No.26。入力欄の文字が 16px なので、iOS で入力時に自動で拡大される問題は起きない（WO-009 で入力欄の文字を 16px にそろえる前提を崩さない）。
- **S-6（名前の無いボタン）**: 地図の配置の帯の「×」に、何をするボタンかの名前（`aria-label`。例「配置をやめる」）を付ける＝No.27。
- **S-7（下のタブ）**: 今いるタブに `aria-current="page"` を付け、色だけでなく**形**でも示す（例: タブの上端の線。案A の見本と同じ）＝No.28。
- **S-8（変えないもの）**: 機能・データ・色の値・文字の大きさ・文言・画面の構成は変えない。押す範囲を広げたことで起きる見た目の小さな変化（行の高さが少し増える等）は許容し、375px で横にはみ出さないこと。

### 前提・不変条件
- DB 変更なし。`docs/デザインの決まり.md` の決まり（トークンだけを使う・直書き禁止・透明度付きの禁止）を守る。
- 地図のピンの色の方針・デモ表示モードは変えない。

### 境界ケース（E-n）
- **E-1**: 一覧のカードの「編集」「削除」「変更履歴」を、スマホで隣を押し間違えずに押せる（範囲が重ならない）。
- **E-2**: ダイアログの「×」を押すとダイアログが閉じる。Tab で「×」に移ると輪が見える。
- **E-3**: 主ボタン（藍の塗り）・削除ボタン（危険の塗り）に Tab で移ると、輪と塗りの間にすき間があり見分けられる。
- **E-4**: 地図の上でピンチしたとき、地図の拡大縮小として動く（ページ全体の拡大と取り合わない）。地図の外でピンチすると、ページが拡大される。
- **E-5**: 下のタブで今いる場所が、色を見なくても（形で）分かる。読み上げで「現在のページ」と伝わる。
- **E-6**: 375px で、ログイン・地図・一覧・小学校マスタのどれも横にはみ出さない。
